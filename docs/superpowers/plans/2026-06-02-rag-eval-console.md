# RAG Eval Console Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rework `/datasets` into a left-nav RAG evaluation console with reports, run records, launch controls, datasets, and a persistent background job rail.

**Architecture:** Keep the existing single-file Python HTTP server and generated HTML pattern. Add focused helper functions in `rag_eval_pipeline/api.py` for evaluation-run manifest scanning and job progress normalization, then render the console UI from `render_upload_page()`.

**Tech Stack:** Python `http.server`, inline HTML/CSS/JavaScript generated by `rag_eval_pipeline/api.py`, pytest.
